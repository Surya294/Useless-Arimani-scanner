### Project Description
Arimani Scanner is an AI-powered web application inspired by the popular Malayalam proverb, "Every grain of rice carries the name of the person destined to eat.

### The Problem (that doesn't exist)
People are unaware of whose name is written on every rice.

### The Solution (that nobody asked for)
AI-powered technology to solve the crisis of rice grains having no names.
